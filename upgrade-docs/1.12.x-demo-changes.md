# Demo Sweep — SWC 1.12.x — Change Log

This file records the results of the DEMO PLUGIN UPGRADE sweep run against
`upgrade-docs/1.12.x-demo-upgrade-plan.md`. Each numbered section below covers one wrapper
package (`theme`/`shared`/`utils` excluded — non-visual, no demo page), in the same order as the
plan's layer table. For each component: pinned version used for the manifest lookup, whether the
existing demo page was already complete or gaps were found, and (if gaps were found) exactly what
was added. Any suspected wrapper/demo bug surfaced during the audit is flagged inline and also
summarized in the table below for follow-up — this mode does not fix `packages/` wrapper source,
only demo-page content (pre-existing UXP-incompatible CSS and one invalid attribute value found
*in demo markup itself* were corrected in place, since those are demo-file defects, not wrapper
bugs).
